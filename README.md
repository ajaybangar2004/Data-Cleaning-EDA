# Data Cleaning and Exploratory Data Analysis (EDA)

## Project Overview
This project demonstrates basic data cleaning and exploratory data analysis using Python.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Features
- Identify missing values
- Fill missing Age and Salary values using the mean
- Calculate average, maximum, and minimum salary
- Identify employees with the highest and lowest salaries
- Filter employee records by age and salary
- Visualize employee salaries using a bar chart
- Export cleaned data to a CSV file
- Verify missing values after cleaning

## Files
- `project 1.py` — Python source code
- `cleaned_data.csv` — Cleaned employee dataset

## How to Run
Install the required libraries:

```bash
pip install pandas matplotlib
```

Run the program:

```bash
python "project 1.py"
```

## Learning Outcomes
Practiced data cleaning, data filtering, descriptive statistics, data visualization, and CSV file handling using Python.
